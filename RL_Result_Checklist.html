Setup instructions (one time)
1. Open https://console.firebase.google.com and sign in with any Google account. 2. Create a project (the free "Spark" plan is enough). 3. Open the project: Build ▸ Firestore Database, then create the database. 4. Click the Web icon (</>) to register an app, then copy the block that starts with "firebaseConfig = { ... }" and paste just the { ... } part into the box above. 5. In Firestore ▸ Rules, set the rules below so both of you can read and write: rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /checklists/{docId} { allow read, write: if true; } } } 6. Give your teammate the same Checklist ID + same config to paste, and both click "Save & Connect". Keep the Checklist ID private - anyone who has it and the config can edit this checklist. Tip: data also stays saved locally in each browser, so nobody loses work if sync is off.
